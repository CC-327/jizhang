# 兼职收入账本 PWA
> 一个渐进式网页应用(PWA)，用于记录兼职收入，支持离线使用，可以添加到手机桌面。

## ✨ 功能
- 记录兼职收支账目
- 离线访问（Service Worker）
- 支持添加到设备桌面，像原生APP一样打开
- 轻量化，纯前端实现
- 本地自动存储，内置备份提醒机制

## 🛠 技术栈
HTML + JavaScript + PWA(Service Worker + Web Manifest)

## 🚀 在线预览
[在线访问](https://cc-327.github.io/jizhang/)

## 📂 项目文件说明
- `index.html`：页面主体
- `sw.js`：离线缓存脚本
- `MANIFEST.webmanifest`：PWA配置清单
- `图标/`：应用图标资源

## 📖 使用方式
打开网页，在浏览器菜单选择【添加到桌面】，即可离线使用。

## 💾 数据存储与备份说明
### 保存：全自动，零操作
每记一笔、改一笔、删一笔，当场就写入浏览器本地存储，无需手动点击保存按钮。关闭页面、关机、断网，数据都保留在当前设备浏览器中。

### 备份：手动，但有提醒
备份是将数据导出到浏览器外部，防止手机丢失、恢复出厂、浏览器数据被清空等极端情况。项目内置备份提醒：
- 超过 7 天没有备份，或新增 10 条以上账目记录 → 打开应用时顶部弹出绿色提醒条
- 点击提醒，可选择导出文件 / 复制备份文本，完成备份后提醒重置，重新开始计数
> 推荐习惯：看到提醒时复制备份文本，发送到微信文件传输助手快速保存。

### 扩展方案（可选升级）
若需要多端实时同步（手机、电脑共用同一套账目，云端永久保存），可升级云同步版本，现有本地账目数据支持直接迁移。

## 💡项目亮点
本项目基于PWA技术，无需安装，浏览器一键添加到桌面；依靠Service Worker实现离线存储，断网依旧可以查看和录入账目，适配手机、电脑多端访问。
